# Desafio Técnico – Processo Seletivo

Este repositório contém a resolução dos desafios propostos para a etapa técnica do processo seletivo de estágio em Desenvolvimento de Software.

## Tecnologias utilizadas

* Java
* Stream API
* Collections Framework
* LocalDate

## Estrutura

O projeto está dividido em dois desafios:

### Desafio 1 – Validador de Senhas

Implementação de uma função responsável por validar uma nova senha considerando:

* Tamanho mínimo de 8 caracteres;
* Presença de letra maiúscula, minúscula, número e caractere especial;
* A senha não pode conter o nome do usuário;
* A senha não pode ser igual a nenhuma das últimas três senhas utilizadas.

### Desafio 2 – Analisador de Vendas

Processamento de uma lista de vendas considerando apenas o ano de 2026, calculando:

* Faturamento total;
* Produto mais vendido em quantidade acumulada;
* Lista de vendas com compras em lote (quantidade maior ou igual a 3).

## Como executar

1. Clone este repositório.
2. Abra o projeto em sua IDE de preferência.
3. Execute a classe `Main` de cada desafio.
